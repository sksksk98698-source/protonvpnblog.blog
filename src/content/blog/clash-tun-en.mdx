## Why TUN Virtual Network Adapters Outperform System Proxies

Standard system proxies only intercept HTTP/HTTPS traffic on port 7890, leaving CLI tools (Git, curl, Docker), game engines, and UDP traffic completely unproxied.

By activating **TUN Mode**, Clash creates a virtual kernel network adapter (Wintun / utun) that captures 100% of layer-3 IP packets, providing transparent, leak-free proxying across all applications.

### Key Configuration Essentials

1. **Service Mode Installation**: Ensure Clash Verge has system privileges to bind virtual adapters.
2. **Fake-IP Implementation**: Reduces DNS roundtrip latency to 1ms by returning virtual `198.18.0.0/16` addresses while proxying the actual DNS query over remote IEPL nodes.
